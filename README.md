# Pepperwood Community Newsletter Archive

A public archive of the Pepperwood Community Newsletter, so neighbors can catch up on past issues.

Live site: https://happy2btct.github.io/pepperwood-newsletter/

## How to add a new issue

1. Put the new issue page in the `issues/` folder. Use a name like `YYYY-MM-DD-issue-NN.html`. For example, Issue 09 lives at `issues/2026-11-11-issue-09.html`.
2. Put that issue's images in `issues/images/` (or a subfolder) and link them from the issue page.
3. Open `index.html` and add a new item at the top of the issue list (newest first). Include the issue number, the date, and a link to the issue file.

You can copy an existing issue page as a starting point and replace the content. All pages share `style.css`. No build step is required. After you push to the `main` branch, GitHub Pages will update the live site.
